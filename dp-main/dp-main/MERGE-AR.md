# دفعة العيادة 4 — مضبوطة على نسختك الأخيرة (dp-main-sections-1-2)

الملفات هنا فقط: المعدّل والمضاف. انسخها فوق مشروعك بنفس المسارات.

## بعد النسخ
1. `npm install` ثم `npx expo install expo-print expo-speech-recognition`
2. أعد بناء نسخة التطوير (مكتبتان أصليتان): `npx expo run:android`
3. الهجرة `0007_clinic_extras.sql` مطبّقة مسبقًا على مشروع Supabase (3 جداول بسياسات RLS).

## أين صارت المداخل (لا توجد شاشة «المزيد» في نسختك)
- دخلي الشهري وجدولة الدوامات: الإعدادات ← التخصيص، وكذلك البحث الشامل.
- قائمة الأسعار / الانتظار / سجل التعقيم: درج أدوات العيادة (المقبض على حافة تبويب العيادة).
- شريط التنبيهات الطبية وبانر الموعد الشاغر: بطاقة الموعد في تبويب العيادة.

## تكيّف مع أماكن العمل المخصّصة
- دخلي الشهري: أجر يوم لكل نوع نشط (المشفى، المناوبة، w1..w8).
- جدولة الدوامات: المنبّه الافتراضي من `defaults.alarmMinutes` لكل نوع.
