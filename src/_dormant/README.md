# كود احتياطي غير مفعّل (Dormant)

لا يستورده أي ملف في التطبيق، ولا يُسجَّل في app.json أو الموجّه، فلا يؤثر على البناء أو التشغيل.
الغرض: حفظ تصميم جاهز لميزتين مؤجلتين لحين الحاجة.

1. `themes.ts` — أنماط تصميم (ثيمات) كاملة.
2. `widgetCatalog.ts` — كتالوج ودجات إضافية للشاشة الرئيسية.

## للتفعيل لاحقًا
- الأنماط: أضف `theme: ThemeId` إلى `Settings` و`DEFAULT_SETTINGS` و`partialize`، ثم طبّق
  `THEMES[theme]` عند القراءة كما يفعل `applyTypeColors`، وانقل القيم الثابتة في الشاشات (مثل #1E2229) إلى هذه الرموز.
- الودجات: لكل ودجت أنشئ مكوّنًا في `src/widgets/`، وسجّله في `widget-task-handler.tsx`
  وفي إضافة `react-native-android-widget` داخل app.json، واكتب لقطة بيانات في `widgetData.ts`
  (سياق الودجت لا يحمّل متاجر التطبيق). يحتاج إعادة بناء التطبيق.
